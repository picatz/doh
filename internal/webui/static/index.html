      Tenants

      Share this server with other households. Each tenant manages its own profiles, devices, query log, and people, and sees no one else's. Its profiles select devices by DoH path or host name, or by address within the networks you give it.

      Security

      Passkeys sign you in with Face ID, Touch ID, Windows Hello, or a security key. Once anyone has one, sign-in links from doh ui need a passkey to finish.
